## Hypotheses and scope

[confirmed] (Adam Zvada, 2026-09-28): investigate the frozen app, check XO, test longer conversations and reuse existing memories. Live calls are authorized with a $2 total cap after restoring OpenAI credits.

[inferred] H1: complete paged imports preserve older flat notes, topics and eligible summaries beyond prompt limits, without reviving forgotten material.

[inferred] H2: the product's published SDK and memory tools preserve an explicitly saved fact across at least 20 intervening conversational turns and a fresh session. Background checkpoints retain evidence; recall and source reads return matching source text.

[inferred] H3: correction removes the superseded active fact; forgetting prevents later recall in a fresh conversation, including imported aggregate context.

## Method and budget

Use authored fictional inputs only. Check large imports with deterministic providers and the Firestore emulator. Run a longer live memory conversation with real OpenAI extraction, embeddings, ranking and tool decisions, using the product memory functions. Preserve prompts, tool receipts, model responses and checks in ignored evidence directories. This is a product continuity test, not a comparative benchmark or clinical evaluation.

Reuse `evals/transport.ts` for HTTP calls: conservative pre-request reservations, failed-call reservations retained, no retries, cache-only replay. Share a $2 cap over the run and record actual token estimates separately. Use explicit model prices from the official OpenAI model pages, checked before calls: GPT-5.6 Luna $0.20/$1.20 input/output per million tokens; text-embedding-3-small $0.02. Reserve at higher $0.40/$1.80 language-model rates to cover long-context pricing and cache-write overhead. No audio generation is required for this memory test.

XO lifecycle uses the maintained `verify-xo` recipes; native loading recovery uses a synthetic invalid chat document with valid child messages. Keep these evidence layers separate: a tool-level model test does not prove continuous native voice behavior. Any remaining untested interaction must be named in the results.
