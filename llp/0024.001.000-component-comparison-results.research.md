## Question and implementation

[confirmed] (Adam Zvada, 2026-09-28): can the TypeScript SDK be tested and scored, and can models, routers and Jev
be swapped as independent building blocks?

[observed] `packages/core/src/memory.ts`, `packages/core/src/pick.ts`, `packages/eval/`, `evals/compare.ts`:
- Independent extraction, link, dossier and ranking model overrides, and a separate repetition detector.
- A `Picker` port with model, closed-question, vector-order and per-kind routing implementations. Returned IDs
  must be unique, within the supplied candidate set, and within the keep limit. Both stores are still searched.
- Processor policy covers all configured stage providers, pickers and detectors before calls.
- A portable `@fluiddb/eval` package exports the dataset validator, `evaluate` and paired `compare`. Factories
  provide fresh stores; failed variants are unscored, errors are redacted, and owned connections are closed.
- A comparison CLI shares one cache/transport/budget across variants, with real OpenAI and Jev adapters.

The historical relational planner and fact/routine/period routing remain archived research components. This work
does not pretend that choosing a picker by candidate kind ports that architecture.

## Frozen fixture and protocol

The hypotheses and $3 cap were declared in LLP 0024.001 before live calls. The original 15-probe, 50-check
`evals/fixtures/conversations.json` was retained; only the explicit `synthetic: true` declaration was added.
Its parsed canonical JSON SHA-256 is:

`2b20a356eac101db0c168b06a6bdec49b18b97215c23e1269dd5c51d3036aa4e`

Every variant used a fresh SQLite database, deterministic IDs/clock and the same keep limits: 2 windows and 3
statements. Ingestion, extraction, linking, embedding, dossier updates, recall and forgetting used the real SDK.
Gold was used only after recall. The fixture includes distractors, five repeated facts, person isolation,
deletion and delayed redelivery. No private research data went to live providers.

Real models: `gpt-6-luna` (low reasoning, 4,096 maximum completion tokens), `text-embedding-3-small`, and
`typesafe/jev-1.13`. The first three variants used the OpenAI closed-question detector; `jev` and `routed` used
Jev detection. `routed` ranked statements with the LLM and windows with Jev. Extraction/linking/dossier models,
embedding and input history were identical across variants. No prompts, thresholds or labels were tuned after
seeing results; the production default was not changed.

All five had identical per-probe checks and zero paired improvements/regressions. Each also passed literal

[inferred] This fixture has a ceiling effect: vector order already passes everything. It establishes a working
integration and regression baseline, not a ranking of the variants. Source hits are graded at whole-window
granularity even for statements, so they can overcount a desired fact in a multi-fact window. These are not
generated-answer scores, general memory accuracy, or clinical outcomes. Harder held-out multi-session,
temporal-change and similar-but-new-fact examples are needed before choosing a production configuration.

The public aggregate report includes the full non-secret config. Copy its `live.config` to an ignored config
file on another machine. A cache miss stays an error unless live mode and a budget are explicitly requested.
No packages were published, no service was deployed, and the therapist backend was not changed.
