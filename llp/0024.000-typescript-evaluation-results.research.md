## Protocol and results

The protocol was written before running. `evals/fixtures/conversations.json` is newly authored synthetic data:
ten distinct memory topics, multiple people, a repeated fact, source deletion and a delayed retry.
Its SHA-256 after formatting is `7d2e555a9ec7965ae07e2dc2a1e46a11a47809896c2c13a3e213c1a2cef490da`.

`bun run eval` uses deterministic testing providers with the production Memory API and SQLite adapter.
Keep limits: two windows and three statements. All **15 probes / 50 explicit checks passed**:

| check | passed / total |
|---|---|
| source-window hit among selected windows | 10 / 10 |
| source-window hit among selected statements | 10 / 10 |
| expected literal text present | 6 / 6 |
| repetition selected the labelled source | 5 / 5 |
| repetition present / absent as labelled | 10 / 10 |
| forbidden literal text absent | 5 / 5 |
| unknown person has empty memory | 1 / 1 |
| forgotten source absent from returned evidence | 3 / 3 |

Repetition presence: 5 true positives, 5 true negatives, 0 false positives, 0 false negatives. These numbers describe
the synthetic providers and fixtures only. There was no threshold tuning after the first successful run.

| hypothesis | outcome |

| H2: cache-only and budget boundaries | passed; tests cover cache misses, cached production adapter calls, parallel reservations, failed requests, cancellation, missing prices/budgets and unpriced models |

## Limits and next work

The new runner makes TypeScript evaluations possible. It does not port every historical benchmark or demonstrate
parity with the lab's real-conversation scores. Source-window grading can overcount a statement from a multi-fact
window; use a more specific semantic grader before making claims about that distinction. Real-model accuracy,
retelling false positives, load and latency remain unmeasured here. A future quality round needs a frozen dataset,
predeclared hypotheses and an explicit budget under LLP 0001.
